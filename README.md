# Thulasi Ram Ruppa Krishnan — Personal Website

Static personal portfolio for https://truppakr.github.io/.

## Publish with GitHub Pages

1. Create a public GitHub repository named `truppakr.github.io` under `truppakr`.
2. Upload all files in this directory to the repository root, including `.nojekyll`.
3. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. GitHub will display the published URL when deployment completes.

This publishes the website and the downloadable résumé publicly, including the contact details in the résumé.

## Files

- `index.html` — biography, career history, skills, certifications, contact, and page structure
- `style.css` — responsive layout and light/dark themes
- `app.js` — work initiatives, filters, case studies, theme toggle, and interactive vector field
- `Thulasi_Ram_Resume.pdf` — downloadable résumé
- `.nojekyll` — serves the static files without Jekyll processing

No package installation or build command is required. Fonts load from Google Fonts, with local fallback fonts.
